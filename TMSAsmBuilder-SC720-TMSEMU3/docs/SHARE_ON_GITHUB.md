## First push

From inside the extracted repository folder:

```text
git init
git add .
git commit -m "Initial TMS ASM Builder IDE release"
git branch -M main
git remote add origin https://github.com/YOURNAME/TMSAsmBuilder-SC720-TMSEMU3.git
git push -u origin main
```

## Release ZIP

For a GitHub release, attach this repository ZIP or run:

```text
publish_win_x64.bat
```

Then zip the `Release/TMSAsmBuilder-win-x64` folder if you want a smaller runtime package.
