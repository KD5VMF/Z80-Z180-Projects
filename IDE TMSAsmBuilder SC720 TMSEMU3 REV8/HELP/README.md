# HELP folder

This folder is the full user and maintainer manual for **TMS ASM Builder IDE for SC720 / TMSEMU3**.

Start here:

1. `01_FULL_USER_MANUAL.md` — complete manual for using the IDE.
2. `02_GIVE_THIS_TO_CHATGPT.md` — copy/paste this into ChatGPT when asking it to write code for this device.
3. `03_WRITING_ASM_FOR_THIS_IDE.md` — practical rules for making Z80/TMS9918A CP/M programs that build cleanly here.
4. `04_TERA_TERM_AND_CPM_TRANSFER.md` — XMODEM and paste-ready HEX workflows.
5. `05_TROUBLESHOOTING.md` — common failures and fixes.
6. `06_IDE_INTERNALS_FOR_MAINTAINERS.md` — how the builder works internally.
7. `07_GITHUB_REPO_SHARING_TEXT.md` — ready-to-use GitHub description and release notes.
8. `08_CREDITS_AND_LINKS.md` — tools, upstream projects, and credits.

The most useful file for making new code with AI help is:

```text
02_GIVE_THIS_TO_CHATGPT.md
```
