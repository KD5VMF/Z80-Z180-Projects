# Credits and links

This repo is a wrapper/helper project. It exists because several excellent projects already make this possible.

## sjasmplus

Purpose in this repo:

- Assembles Z80/Z180-style source on Windows.
- Builds raw `.COM` style output using the IDE's `--raw="{out}" "{src}"` argument pattern.

Links:

```text
https://github.com/z00m128/sjasmplus
https://z00m128.github.io/sjasmplus/documentation.html
https://github.com/z00m128/sjasmplus/releases
```

## J.B. Langston TMS9918A project

Purpose in this repo:

- Source of the TMS9918A/TMSEMU3 support files and examples.
- Important files include `tms.asm`, `tmsfont.asm`, `z180.asm`, and `utility.asm`.

Links:

```text
https://github.com/jblang/TMS9918A
https://github.com/jblang/TMS9918A/tree/master/examples
```

## RomWBW

Purpose in this workflow:

- Common system software for many Z80/Z180/Z280 retro-computers.
- Provides CP/M-style environments and tools used on Small Computer Central / RC2014-style systems.

Links:

```text
https://github.com/wwarthen/RomWBW
```

## Small Computer Central SC720

Purpose in this workflow:

- The SC720 is one of the target Z80/RomWBW/CP/M systems this IDE was made around.

Links:

```text
https://smallcomputercentral.com/rcbus/sc700-series/sc781-rcbus-z80-sbc-motherboard/
https://lectronz.com/products/sc720-rcbus-80pin-z80-romwbw-cpm-motherboard
```

## Tera Term

Purpose in this workflow:

- Windows serial terminal used to transfer `.COM` files with XMODEM or paste/send Intel HEX text to CP/M.

Links:

```text
https://teratermproject.github.io/index-en.html
https://github.com/TeraTermProject/osdn-download/releases
```

Links:
