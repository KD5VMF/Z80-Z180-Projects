# Contributing

Contributions are welcome, especially:

- more tested SC720/TMSEMU3 demo programs,
- better syntax coloring rules,
- safer build/logging behavior,
- clearer CP/M transfer instructions,
- better packaging for non-developer Windows users.

Please keep the main rule intact: timestamped build folders should stay clean and contain only the generated `.ASM` and `.HEX` files. Shared support libraries belong in `TMSAsmBuilder/Libs`.
