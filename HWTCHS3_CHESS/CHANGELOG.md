# Changelog

## HWTCHS3

- Added ANSI color output.
- Added total wins display.
- Added separate visual colors for board, pieces, move markers, and status text.
- Kept slower/fun-to-watch self-play behavior from HWTCHS2.
- Kept changed-square updates to avoid full-screen flashing.

## HWTCHS2

- Fixed the flashing from full-screen redraws.
- Board draws once, then only changed squares update.
- Slowed down the game so moves can be watched.
- Added thinking/search/plan style status text.
- Added `+` and `-` speed controls.

## HWTCHS1

- First CP/M 8080-safe chess board self-play version.
- ANSI board display.
- Automatic book-style match.
- Q exits back to CP/M.
