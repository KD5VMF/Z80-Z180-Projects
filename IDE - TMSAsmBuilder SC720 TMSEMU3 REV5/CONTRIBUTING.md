# Contributing

Small improvements are welcome.

Good contribution areas:

- More tested SC720/TMSEMU3 templates.
- Better syntax coloring.
- More transfer notes for RomWBW CP/M.
- Example programs that build cleanly with the included library style.
- Documentation fixes.

Please keep this project beginner-friendly. The goal is not to hide the Z80 details forever; the goal is to make it easy to get from ASM source to a real CP/M program running on the hardware.

## Style

- Keep examples CP/M `.COM` compatible with `org 100h`.
- Keep generated output names 8.3-safe.
- Preserve third-party copyright/license headers.
- Prefer complete working examples over fragments.
